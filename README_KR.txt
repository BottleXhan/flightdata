FlightData (Windows)
====================

OpenSky Network 의 공항 운항 기록을 받아서, 같은 창에서 바로 시간대·일·요일·월별 운항과 노선·항공사·기종을 보는 프로그램입니다.
설치 없이 FlightData.exe 를 더블클릭하면 됩니다. (Python 필요 없음)

[처음 한 번]
- OpenSky 계정(https://opensky-network.org)과 Trino(과거 데이터) 사용 승인이 필요합니다.
- 처음 실행할 때 Windows 가 "PC 보호" 경고를 띄우면 [추가 정보] → [실행] 을 누르세요.
  (회사 보안 정책으로 실행이 막히면 IT 담당자에게 문의하세요.)
- 창은 Windows 에 들어 있는 Edge WebView2 로 그립니다. 창이 안 뜨는 PC 에서는 브라우저로 열립니다.

[받고 보기]
1. 왼쪽 "개요" 탭의 1 데이터에서 "OpenSky에서 받기" 를 고릅니다 (처음에는 이미 골라져 있습니다).
2. OpenSky 사용자명과 비밀번호를 넣습니다.
   "이 PC에 비밀번호 기억" 을 켜 두면 Windows 자격 증명 관리자에 암호화해 저장되어 다음부터 입력하지 않아도 됩니다.
   (개인 PC 에서만 켜세요. 끄고 받으면 저장된 비밀번호도 지워집니다.)
   비밀번호를 비우면(Google·GitHub 로 가입한 계정 등) 브라우저에 OpenSky 로그인 창이 열리고, 로그인하면 이어집니다.
3. 2 공항·기간에서 공항을 고릅니다. "공항 찾기" 에 이름·도시·한글(예: 인천, 하네다, Frankfurt)을 넣으면 목록이 나옵니다.
   기간은 날짜 칸이나 [7일] [30일] [연도 선택] 으로 고릅니다. 여러 해는 연도 표에서 시작 연도 → 끝 연도를 차례로 누르세요.
4. [CSV 받고 보기] 를 누르면 하루씩 받고, 다 받으면 같은 창에서 바로 분석 화면이 나옵니다.
   CSV 는 저장 폴더(기본: FlightData.exe 옆 OpenSky_CSV 폴더)에 RKSI_시작일_종료일.csv 로 남습니다.
5. 받은 데이터는 프로그램에도 저장되어, 다음에 켜면 마지막 데이터가 바로 열립니다 (1 데이터 → CSV 파일 → 저장된 데이터).

[알아 두기]
- 하루씩 차례로 받습니다. 1년치는 오래 걸리니 처음엔 며칠로 시험해 보세요. [받기 중지] 로 멈출 수 있습니다.
- 받은 날짜는 저장 폴더의 trino_cache 에 남아 다시 받지 않습니다. 중지하거나 창을 닫아도 이어받을 수 있습니다.
- 설정·항공기 DB(aircraftDatabase.csv)·프로그램 데이터는 exe 와 같은 폴더에 저장됩니다. exe 를 쓰기 가능한 폴더(예: 바탕 화면의 새 폴더)에 두세요.
- OpenSky 조회 규칙(하루 단위, 한 번에 하나씩)을 지킵니다. 계정을 여러 개 만들면 정지될 수 있습니다.
- 공항 목록: mwgg/Airports (MIT License). 지도: Natural Earth.
- 비상업적 연구용 데이터입니다. 발표·논문에 쓰면 인용하세요:
  Schäfer et al., "Bringing Up OpenSky: A Large-scale ADS-B Sensor Network for Research", IPSN 2014.
