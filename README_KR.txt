FlightData 수집기 (Windows)
================================

FlightData 분석기에 넣을 CSV 를 OpenSky Network 에서 받는 프로그램입니다.
설치 없이 FlightData_Collector.exe 를 더블클릭하면 됩니다. (Python 필요 없음)

[처음 한 번]
- OpenSky 계정(https://opensky-network.org)과 Trino(과거 데이터) 사용 승인이 필요합니다.
- 처음 실행할 때 Windows 가 "PC 보호" 경고를 띄우면 [추가 정보] → [실행] 을 누르세요.
  (회사 보안 정책으로 실행이 막히면 IT 담당자에게 문의하세요.)

[CSV 받기]
1. OpenSky 사용자명을 넣고 공항을 고릅니다.
   - ICAO 코드를 모르면 오른쪽 "공항 찾기" 에 이름·도시·IATA·한글(예: 인천, Tokyo, ICN)을 입력하거나 지도를 누르세요.
   - 공항을 고르면 공항명·위치가 나오고, 공항 시간대에 맞춰 UTC 오프셋이 자동으로 바뀝니다.
2. 기간은 달력에서 고릅니다. 기본은 오늘까지 최근 7일이며, [최근 7일] [최근 30일] 과 1년 단위 버튼(예: 2024, 2025, 2026 — 올해는 오늘까지, 그 전은 '이전 연도' 목록)도 있습니다.
   여러 해(N년)는 '여러 해' 에서 시작·끝 연도를 고르고 [적용]. '연도별로 CSV 나누기' 를 켜 두면 1년마다 CSV 가 따로 생깁니다.
   분석기에서 같은 공항 CSV 여러 개를 한꺼번에 고르면 전체 기간을 합쳐서 봅니다.
3. [CSV 받기] 를 누르면 브라우저에 OpenSky 로그인 창이 열립니다. 로그인하면 자동으로 이어집니다.
4. 진행 막대가 끝나면 저장 폴더(기본: 문서\OpenSky_CSV)에 RKSI_시작일_종료일.csv 가 생깁니다.
5. [분석기 열기] → 왼쪽 "운항 CSV 파일" 에서 그 CSV 를 고르고 [데이터 보기].

[알아 두기]
- 하루씩 차례로 받습니다. 1년치는 오래 걸리니 처음엔 며칠로 시험해 보세요.
- 받은 날짜는 저장 폴더의 trino_cache 에 남아 다시 받지 않습니다. 중지하거나 창을 닫아도 이어받을 수 있습니다.
- 입력값과 항공기 DB(aircraftDatabase.csv)는 exe 와 같은 폴더에 저장됩니다. exe 를 쓰기 가능한 폴더(예: 바탕 화면의 새 폴더)에 두세요.
- OpenSky 조회 규칙(하루 단위, 한 번에 하나씩)을 지킵니다. 계정을 여러 개 만들면 정지될 수 있습니다.
- 공항 목록: mwgg/Airports (MIT License). 지도: © OpenStreetMap 기여자 (인터넷 연결 필요).
- 비상업적 연구용 데이터입니다. 발표·논문에 쓰면 인용하세요:
  Schäfer et al., "Bringing Up OpenSky: A Large-scale ADS-B Sensor Network for Research", IPSN 2014.
