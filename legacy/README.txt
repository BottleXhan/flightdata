OpenSky 첨두시간 분석기 (내 PC 실행판)
=====================================

[처음 한 번]
1. Python 3.13 이 필요합니다. PowerShell 에서:  py install 3.13
   (이미 설치했다면 건너뛰기)
2. 이 폴더의 압축을 원하는 곳에 풉니다 (예: 바탕 화면\OpenSky_Analyzer).

[매번]
1. Start_OpenSky_Analyzer.bat 을 더블클릭합니다.
   - 처음 실행할 때 필요한 프로그램(trino)을 자동으로 설치합니다.
   - Windows 가 "PC 보호" 경고를 띄우면 [추가 정보] → [실행].
2. 브라우저에 분석기가 열립니다.
3. 데이터 소스가 "OpenSky Trino (내 PC)" 로 선택되어 있습니다.
   OpenSky 사용자명, 공항, 기간을 확인하고 [데이터 수집 및 ICAO 기준 피크 산정] 을 누릅니다.
4. OpenSky 로그인 창이 열리면 로그인합니다. 진행 상황이 화면에 표시되고, 끝나면 바로 분석 결과가 나옵니다.
5. 다 쓰면 검은 창을 닫습니다.

[알아 두기]
- 받은 날짜는 trino_cache 폴더에 저장되어 다시 조회하지 않습니다. 1년치는 처음 한 번만 오래 걸립니다.
- 결과 CSV 도 이 폴더에 저장됩니다 (예: RKSI_2025-01-01_2025-12-31.csv).
- 검은 창은 분석기가 쓰는 작은 서버입니다. 이 PC 에서만 접속되며, 창을 닫으면 종료됩니다.
- OpenSky 조회 규칙(하루씩, day 파티션 필터, 한 번에 하나씩)을 지킵니다. 코드를 고쳐 쓰지 마세요.
- 논문·발표에 쓰면 OpenSky 원 논문을 인용하세요: Schäfer et al., "Bringing Up OpenSky", IPSN 2014.
